2) Reglas de negocio y RBAC (visibilidad y permisos)
2.1 Acciones sensibles (según lo definido)

Exportar XTF (Modelo Extendido Antioquia / XTF 1.0 IGAC)

Admin: permitido siempre

Revisión de Calidad: permitido si conjunto/predio Validado/Aprobado

Reconocedor/Digitador: no permitido

Cargar/Importar XTF

Admin: permitido

Revisión de Calidad: permitido para revisión/integración

Reconocedor/Digitador: no permitido

Preparar/Cargar GDB

Admin: permitido

Revisión de Calidad: permitido (verificación/validación)

Reconocedor/Digitador: solo lectura (consulta)

2.2 Visibilidad de UI (ejemplos)

Ocultar/Deshabilitar botones de Exportar/Cargar XTF y Preparar GDB si el rol no lo permite o si el estado ≠ Validado/Aprobado (para Revisión).

Mostrar tooltips con motivo de restricción.

Registro de intentos no autorizados como evento de seguridad.

4) Contrato API (mínimo sugerido para integrar)

Auth

POST /auth/login → { user|email, password } ⇒ { accessToken, refreshToken?, mfaRequired }

POST /auth/mfa/verify → { code } ⇒ tokens

POST /auth/forgot → { email }

POST /auth/reset → { token, newPassword }

POST /auth/change-password → { currentPassword, newPassword }

POST /auth/logout → revoke

GET /auth/me → perfil + roles + permisos

Usuarios

GET /users?role=&q=&state= → listado

POST /users → crear

PUT /users/:id → editar (roles, estado, mfaRequired, forcePasswordChange)

POST /users/:id/reset-password → dispara email

POST /users/:id/sessions/revoke → cierra sesiones del usuario

Roles/Permisos

GET /roles / POST /roles / PUT /roles/:id

Permisos disponibles (catálogo): GET /permissions

Políticas

GET /security/policies / PUT /security/policies

Sesiones

GET /sessions → activas

POST /sessions/revoke → masivo

Auditoría

GET /audit?from=&to=&user=&type=&module=

GET /audit/:id

XTF/GDB (sensibles, con RBAC)

POST /xtf/import → subir archivo; retorna jobId

GET /xtf/import/:jobId → estado + reporte

POST /xtf/export → { perfil, alcance } → jobId + downloadUrl cuando finaliza

POST /gdb/prepare → { dataset/capa } → jobId

GET /jobs/:jobId → estado (queued, running, success, failed) + mensajes

5) Modelos de datos (frontend)

User

id, nombre, apellidos, usuario, email, roles[], estado, ultimoAcceso, mfaRequired, forcePasswordChange

Role

id, nombre, descripcion, permisos[]

Permission

id, codigo (e.g., EXPORT_XTF), descripcion, modulo

SecurityPolicy

passwordMinLength, requireUpper/lower/number/special, expirationDays, historyCount

maxFailedAttempts, lockoutMinutes

sessionTimeoutMinutes, enforceMFAForRoles[], ipAllowList[]

Session

id, userId, ip, userAgent, inicio, ultimaActividad

AuditEvent

id, fecha, usuario, ip, tipo, modulo, recursoId, detalle (antes/después/hash/resultados)

Job (procesos XTF/GDB)

id, tipo (import/export/prepare), estado, iniciadoPor, progreso%, mensajes[], resultado (downloadUrl, reporte)
