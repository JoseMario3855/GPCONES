# GPCONES

Sistema de catastro integral GP Cones: API **Node.js / Express**, base **PostgreSQL** y aplicación **React** (carpeta `FRONT`).

## Documentación e inicio para el equipo

- **[Guía de instalación y ejecución](docs/compartir-equipo/README.md)** — requisitos, `npm install`, variables de entorno, puertos.
- **[Índice de toda la documentación](docs/compartir-equipo/INDICE_DOCUMENTACION.md)** — predios, XTF, roles, base de datos, etc.

**Variables de entorno:** copia [`.env.example`](.env.example) a `.env` en la raíz del proyecto y ajusta valores locales. El archivo `.env` no se sube a Git.
